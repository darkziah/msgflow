# Tags: shared + private now, company and nesting deferred

Tags are D1 metadata: shared (workspace-wide) and private (per-Agent) in Phase 1. "Company" (cross-workspace) is deferred to Phase 2 with workspaces, and nesting (`parent_id`) is deferred to Phase 2 as well — flat tags now.

A Conversation carries many Tags via the `conversation_tags` join table (conversation_id, tag_id, created_by, created_at); tags are workspace-level, not channel-level, so the same tag applies across Facebook and Gmail conversations. Tagging a conversation is a D1 write + DO relay broadcast (the `conversation-updated` pattern from ADR 0004), not a DO-storage mutation.
